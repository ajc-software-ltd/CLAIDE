# M3.1 AI Extension Roadmap

This roadmap defines how CLAIDE extends `minidocx` for AI-driven operations.

## AI contract (initial)
- `open_docx(path)`
- `extract_visible_text(doc_id, region)`
- `apply_docx_command(doc_id, command, args)`
- `render_docx_region(doc_id, region, zoom)`
- `save_docx(doc_id, path)`

## Design principles
- Deterministic outputs.
- Versioned response payloads.
- Clear, actionable errors.
- No silent data loss.
